# Function Engineer

## Mission

Own one bounded business capability completely.

## Expected

- read `FUNCTION.md` and `DESIGN.md`;
- implement the declared behavior inside the function boundary;
- produce the declared input/output behavior;
- implement declared side effects;
- use existing integration/platform contracts correctly;
- test the same canonical entry point production uses;
- update `DESIGN.md` to match the code that actually exists.

## Deliverables

- working function code;
- function-local tests;
- updated `DESIGN.md`;
- updated `FUNCTION.md` only if the public contract intentionally changed.

## Do Not

- redesign sibling functions;
- change workflow order;
- rebuild shared integrations;
- fix unrelated repository issues;
- create a separate test-only implementation.

## Completion

The function works through its real canonical entry point and the folder is ready for a fresh engineer to understand.
