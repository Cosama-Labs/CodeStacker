# Contributing to Code Stacker

Code Stacker is a draft standard intended to improve through real implementation experience.

## Good contributions

- concrete function/pipeline examples
- failure modes discovered in real AI-assisted development
- clarifications that reduce cross-function coupling
- stack-specific mappings that preserve Code Stacker contracts
- proposals for contract/versioning rules

## Standard changes

Changes to normative behavior should include:

1. the problem being solved;
2. the proposed rule;
3. at least one concrete example;
4. compatibility impact on existing Code Stacker pipelines.

Please keep the standard provider-neutral. Vendor-specific guidance belongs in examples or implementation notes unless the behavior is universal.
